#### AFTER (JSON-Driven)
```powershell

$applicableRules = $policy.rules | Where-Object { 
    $_.enabled -and $_.layer -in @("L3", "L4") 
}
```

## Integration Points

### 1. With Backend
- Agent polls: `/api/agent/command` → gets `ACTIVATE/DEACTIVATE`
- Agent reports: `/api/agent/heartbeat` → sends firewall state
- Data saved in: `firewall_agents.json`

### 2. With JSON Policy
- Location: `C:\Users\Public\Documents\firewall_1\hybrid_firewall.json`
- Format: Standard JSON
- Synced via: Web UI or manual copying

### 3. With Windows Firewall
- Rules group: `Enterprise-Hardening`
- API: Windows `NetFirewallRule` cmdlets
- Events: Windows Event Viewer (`Firewall-Escalation` source)
