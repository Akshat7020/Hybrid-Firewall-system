Installation Steps

1

Download the Installer

Click the "Download Installer" button above to get the appropriate script for your OS.

Note: You don't need credentials to download — they'll be created automatically on first run.
2

Run on Target Machine

On Windows: Open PowerShell as Administrator and paste the command shown above.

On Linux: Open terminal and run the command with sudo if needed.

Tip: The installer creates scheduled tasks / systemd services for automatic startup.
3

Collect Generated Credentials

After installation, check these files for your credentials:

Windows: C:\Users\Public\Documents\firewall_1\user_id.txt
Windows: C:\Users\Public\Documents\firewall_1\user_token.txt
Linux: ~/firewall_agent/user_id.txt
Linux: ~/firewall_agent/user_token.txt
4

Sign In Here

Go to the Agents tab, paste your User ID and Token, and click Sign In.

Your agent should appear in the list within seconds. If you don't see it, check the agent logs.

5

Control Firewall

Once signed in, click ACTIVATE or DEACTIVATE to control the firewall on your agent.

Rules are loaded from your centralized firewall policy file (hybrid_firewall.json). Changes take effect instantly across all agents.

Troubleshooting

Agent doesn't appear after installation

1. Check that the installer completed without errors

2. Verify the backend URL is correct (http://10.144.164.253:5000)

3. Check internet connectivity from the agent machine

4. Review agent logs for error messages

Windows logs: C:\Users\Public\Documents\firewall_1\agent.log

Installation command fails

Windows: Ensure you're running PowerShell as Administrator

Windows: Set execution policy if needed: Set-ExecutionPolicy -ExecutionPolicy Bypass -Scope CurrentUser

Linux: Use sudo for system-wide installation or install in home directory

Contact your system administrator if you lack permissions

How to find your credentials

Windows: Run this in PowerShell:

$env:HOMEPATH\firewall_1\user_id.txt

Linux: Run this in Terminal:

cat ~/firewall_agent/user_id.txt
